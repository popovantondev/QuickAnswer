Если после нажатия кнопки расширение не отвечает, теперь окно показывает ошибку до закрытия. На `edge://` и других служебных страницах Edge расширениям запрещён доступ к содержимому; для них попробуйте режим «Другое окно».

**Установка:** распакуйте содержимое ZIP поверх существующей папки `C:\QuickAnswer\edge-quick-answer`, затем в Edge нажмите «Erneut laden». Не удаляйте установленное расширение, иначе его ID/настройки могут измениться. Перед установкой сохраните зашифрованную копию ключей.

Горячие клавиши не меняются: Ctrl+Shift+1, Ctrl+Shift+2, Ctrl+Shift+3, Ctrl+Shift+4. Проверка: откройте обычную страницу HTML, вызовите «Область», обведите вопрос и проверьте статус. По умолчанию используется Groq → Gemini → ChatGPT (Codex Bridge), с учётом сохранённых настроек.

**Ограничение:** выделение области работает внутри доступной вкладки Edge, не поверх чужой Windows-программы. «Другое окно» запускает системный выбор окна/экрана.

# Quick Answer — 1.6.0-preview.1

**RU / DE / EN · Microsoft Edge · Windows 11 · без административной установки.**

## Быстрая установка

1. Распакуйте ZIP целиком в постоянную папку, например `C:\QuickAnswer` (сам код приложения; ключи остаются в профиле Edge).
2. Откройте `edge://extensions` → включите режим разработчика → «Entpackte Dateien laden» и выберите эту папку `edge-quick-answer`, в которой находится `manifest.json`.
3. При обновлении существующего распакованного расширения замените файлы **в прежней папке**, затем нажмите «Erneut laden»; не удаляйте старую установку, пока не проверите ключи.
4. Откройте настройки, выберите RU/DE/EN и добавьте свои ключи Groq/Gemini. Никаких ключей в ZIP нет.
5. Горячие клавиши: `Ctrl+Shift+1` — текст; `Ctrl+Shift+2` — JPEG; `Ctrl+Shift+3` — формат; `Ctrl+Shift+4` — выделение. Если Edge не назначил клавиши, откройте `edge://extensions/shortcuts`.

## Возможности

- Порядок Groq → Gemini → ChatGPT (Codex Bridge) (при настройке и наличии лимитов), автоматическое сохранение настроек, короткие ответы с объяснением и номера вариантов.
- JPEG без уменьшения разрешения, обрезка области, отдельная страница захвата другого окна после разрешения Edge.
- Три языка UI, светлая/тёмная/системная тема. Зашифрованный экспорт/импорт ключей с паролем.
- API-ключи хранятся в профиле Edge; не в публичной папке Windows. Не публикуйте резервные JSON и личные снимки на GitHub.
- Ответы моделей могут ошибаться; цель менее 15 секунд не гарантирует фактическую задержку. Соблюдайте правила учебных тестов.

Полные инструкции: `../docs/Guide-ru.html`, `Guide-de.html`, `Guide-en.html` (если распаковали пакет разработчика). Релизный ZIP содержит только расширение.
