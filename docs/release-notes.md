## English

**Changes:** Initial public source release: Edge 1.7.8 and Windows PowerShell Desktop 0.1.

**Compatibility:** Edge MV3; desktop requires Windows 10/11, Windows PowerShell 5.1, WinForms and .NET Framework. Optional browser Bridge requires separate Node.js/Codex installation and authorization.

**Installation:** Edge ZIP: load `edge-quick-answer` unpacked. Desktop ZIP: open `desktop/START_QuickAnswer.cmd`. No compiled EXE supplied. Preserve the existing Edge extension entry when updating.

**Limitations:** Desktop is untested, partially localized, and incompatible with the bundled browser-only Bridge. Provider availability is unverified; no latency guarantee. Demonstration images show the earlier 1.7.4 UI. Submitted questions/images go to providers. Original-code license has not been selected.

**Checksums:** Verify the attached SHA256SUMS.txt. Static/mocked checks passed; these are not live Windows/Edge/provider acceptance tests.
