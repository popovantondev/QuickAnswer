Быстрые ответы прямо в браузере

Quick Answer помогает анализировать текст и скриншоты в Microsoft Edge. Выбирайте модель, вызывайте действие горячей клавишей и получайте компактный ответ.

01

Установка

Скачайте ZIP из Releases, распакуйте всю папку. Откройте edge://extensions, включите режим разработчика и нажмите «Загрузить распакованное». Выберите папку edge-quick-answer.

02

Быстрый запуск

Нажимайте Ctrl+Shift+1 для текста страницы, Ctrl+Shift+2 для JPEG, Ctrl+Shift+4 для выделения. Ctrl+Shift+3 переключает формат. В другом окне используйте отдельную кнопку захвата с разрешением Edge.

03

Типы вопросов

В АВТО расширение пытается определить формат. Для обычного теста выводятся номера ответов и краткие объяснения, для Kahoot — цвет. При неоднозначности результат нужно проверить вручную.

04

Модели и ключи

В настройках добавьте собственные ключи Groq и Gemini. Последовательное резервирование использует следующий ключ/провайдер при доступных ошибках. ChatGPT требует отдельно запущенного локального Codex Bridge.

05

Диагностика и ограничения

Следите за количеством запросов и временем ответа. Сохраняйте ключи только в профиле Edge или в зашифрованной резервной копии. Данные вопросов передаются выбранному провайдеру. Настоящая совместимость и задержка зависят от среды.

Предварительная версия. Проверяйте ответы модели; не передавайте конфиденциальные материалы и соблюдайте правила тестов.

Windows Desktop 0.1 — неиспытанный исходный Preview

Распакуйте desktop-архив и запустите START_QuickAnswer.cmd. Требуются Windows 10/11, Windows PowerShell 5.1, WinForms и .NET Framework. Скомпилированного EXE нет. Ctrl+Alt+1: экран; 2: активное окно; 4: область. Ключи защищены DPAPI CurrentUser. Изображения отправляются выбранному провайдеру. Запуск, провайдеры, DPI и хоткеи не проверены. Вложенный Bridge принимает только браузерные расширения; desktop с ним пока несовместим.
