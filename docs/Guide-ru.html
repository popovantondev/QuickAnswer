01

Установка

Скачайте ZIP из Releases, распакуйте всю папку. Откройте edge://extensions, включите режим разработчика и нажмите «Загрузить распакованное». Выберите папку edge-quick-answer. При обновлении не удаляйте расширение, а перезагрузите его: новый ID расширения может лишить доступа к сохранённым ключам.

02

Быстрый запуск

Нажимайте Ctrl+Shift+1 для текста страницы, Ctrl+Shift+2 для JPEG, Ctrl+Shift+4 для выделения. Ctrl+Shift+3 переключает формат. В другом окне используйте отдельную кнопку захвата с разрешением Edge.

03

Типы вопросов

В АВТО расширение пытается определить формат. Для вопросов с выбором выводятся номера ответов и краткое обоснование, для заданий только с выбором цвета — цвет. Каждый ответ проверяйте сами.

04

Модели и ключи

В настройках добавьте собственные ключи Groq и Gemini. Последовательное резервирование использует следующий ключ/провайдер при доступных ошибках. ChatGPT требует отдельно запущенного локального Codex Bridge.

05

Диагностика и ограничения

Следите за количеством запросов и временем ответа. Сохраняйте ключи только в профиле Edge или в зашифрованной резервной копии. Данные вопросов передаются выбранному провайдеру. Время ответа не гарантируется.

Предварительная версия. Проверяйте ответы модели, не передавайте конфиденциальные материалы и соблюдайте правила своего учебного заведения.

Desktop 0.1 — неиспытанный исходный Preview

Распакуйте desktop-архив и запустите START_QuickAnswer.cmd. Требуются Windows 10/11, Windows PowerShell 5.1, WinForms и .NET Framework. Скомпилированного EXE нет. Ctrl+Alt+1: экран; 2: активное окно; 4: область. Ключи защищены DPAPI CurrentUser. Изображения отправляются выбранному провайдеру. Запуск, провайдеры, DPI и хоткеи не проверены. Вложенный Bridge принимает только браузерные расширения; desktop с ним пока несовместим.
