Введение в Quick Answer

Quick Answer помогает анализировать текст и скриншоты в Microsoft Edge. Выбирайте модель, вызывайте действие горячей клавишей и получайте компактный ответ.

Ключи хранятся в профиле Edge; текст и изображения отправляются выбранному провайдеру.

ПК: portable-клиент 0.1 (исходный Preview) позволяет захватывать экран и другие окна без установки, Windows-проверка ещё нужна.

Windows Desktop 0.1 — неиспытанный исходный Preview

Распакуйте desktop-архив и запустите START_QuickAnswer.cmd. Требуются Windows 10/11, Windows PowerShell 5.1, WinForms и .NET Framework. Скомпилированного EXE нет. Ctrl+Alt+1: экран; 2: активное окно; 4: область. Ключи защищены DPAPI CurrentUser. Изображения отправляются выбранному провайдеру. Запуск, провайдеры, DPI и хоткеи не проверены. Вложенный Bridge принимает только браузерные расширения; desktop с ним пока несовместим.
