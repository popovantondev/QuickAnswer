Quick Answer —
Учебный помощник в Edge

Quick Answer — учебный помощник для самопроверки и подготовки. Соблюдайте правила своего учебного заведения: использовать его на экзаменах, контрольных работах и оценочных тестах запрещено.

Расширение Edge читает текст или снимок страницы, спрашивает ИИ-провайдера по вашему собственному ключу и показывает короткий ответ с обоснованием, которое можно проверить. Ничего не нажимается автоматически.

Установка

Как в руководстве: скачать ZIP, распаковать, подключить в Edge.

1 Скачать ZIP из Releases и распаковать целиком
2 Открыть edge://extensions, включить режим разработчика
3 «Загрузить распакованное» → папка edge-quick-answer
✓ Quick Answer появляется в Edge

Проверено

  • Более 130 автоматических проверок в GitHub Actions (манифест, интерфейс, языки RU/DE/EN)
  • Экспорт ключей, сопоставление ответов и имитация работы проверяются в CI
  • Опубликованные файлы проверяются на ключи и личные пути
  • Контрольные суммы SHA-256 в релизе (SHA256SUMS.txt)
  • Версия 1.7.8 с журналом изменений

Как это работает

  1. Захватить вопрос: текст, снимок или область
  2. Провайдер коротко отвечает и объясняет
  3. Вы сами проверяете ответ

Desktop 0.1 — неиспытанный исходный Preview

Распакуйте desktop-архив и запустите START_QuickAnswer.cmd. Требуются Windows 10/11, Windows PowerShell 5.1, WinForms и .NET Framework. Скомпилированного EXE нет. Ctrl+Alt+1: экран; 2: активное окно; 4: область. Ключи защищены DPAPI CurrentUser. Изображения отправляются выбранному провайдеру. Запуск, провайдеры, DPI и хоткеи не проверены. Вложенный Bridge принимает только браузерные расширения; desktop с ним пока несовместим.
