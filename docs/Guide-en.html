Quick Answer —
User guide

Quick Answer is a study assistant for self-checking and exam preparation. The rules of your school or university apply: using it in exams, written tests or graded assessments is prohibited.

01

Installation

Download the ZIP from Releases and extract the whole folder. Open edge://extensions, enable Developer mode, choose Load unpacked, and select the edge-quick-answer folder. Do not remove the extension when updating, reload it instead: a new extension ID can lose access to saved keys.

02

Quick launch

Ctrl+Shift+1 reads page text, Ctrl+Shift+2 captures JPEG, Ctrl+Shift+4 selects a region, and Ctrl+Shift+3 cycles the question mode. For another window use Edge’s permission-based screen picker.

03

Question formats

AUTO attempts to detect the type. For multiple choice, Quick Answer returns numbers and a brief reason; for tasks that only pick a colour it returns just the colour. Always verify the answer yourself.

04

Models and keys

Enter your Groq and Gemini keys in Settings. On applicable failures, the extension tries the next available key or provider. ChatGPT requires an independently running local Codex Bridge.

05

Diagnostics and limitations

Watch request counts and response time. Keep keys in your Edge profile or a password-encrypted backup. Text and screenshots are sent to the chosen provider; latency cannot be guaranteed.

Preview release. Verify model responses, protect confidential content, and follow the rules of your school or university.

Desktop 0.1 — untested source preview

Extract the desktop archive and run START_QuickAnswer.cmd. Requires Windows 10/11, Windows PowerShell 5.1, WinForms and .NET Framework. No compiled EXE is supplied. Ctrl+Alt+1 captures the screen, Ctrl+Alt+2 the foreground window, Ctrl+Alt+4 a region. Keys use DPAPI CurrentUser. Images go to the selected provider. Runtime, providers, DPI and hotkeys have not been verified. The bundled Bridge accepts browser extension origins only; desktop is currently incompatible with it.

Desktop 0.1: source only, no EXE; Windows launch not verified.
