# Rights, privacy and distribution

The maintainer has **not yet selected a license for the original project**. Publication of the source does not by itself grant permission for unrestricted reuse, modification, or redistribution. Do not add MIT or another license without the owner's approval.

The repository bundles no third-party JavaScript frameworks, fonts, or model weights. Names and trademarks of Groq, Gemini, ChatGPT, Microsoft and Kahoot are descriptive and do not imply endorsement.

The Edge extension stores credentials in the local Edge profile; no credentials are shipped in the source archive. A separate encrypted backup can be exported by the user; do not commit it. Windows Desktop encrypts individual keys using DPAPI CurrentUser into `%LOCALAPPDATA%\QuickAnswerDesktop\settings.json`; other processes running as the same logged-in user may still have access. The application cannot protect against a compromised Windows account.

Text and JPEG screenshots sent for inference are disclosed to the selected third-party provider. The project does not collect analytics and does not save screenshots by default. Users must respect data privacy and any applicable quiz/school rules.
