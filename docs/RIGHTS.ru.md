# Права, конфиденциальность и распространение

**Используйте только там, где это разрешено.** Quick Answer — учебный помощник для самопроверки и подготовки. Соблюдайте правила своего учебного заведения: использовать его на экзаменах, контрольных работах и оценочных тестах запрещено.

## Права и разрешённое использование

Если автор проекта не добавит отдельную лицензию, исходный код этого репозитория опубликован только для публичного просмотра. Разрешение копировать, изменять, распространять, сублицензировать или продавать исходный код проекта и его изменённые версии не предоставляется. Это не проект с открытым исходным кодом.

Автор проекта разрешает частным лицам скачивать и использовать для личных целей неизменённую опубликованную версию.

Условия сервиса GitHub могут разрешать просмотр и создание форков на платформе. Форк не даёт дополнительных прав на использование проекта за пределами функций платформы.

В репозитории нет сторонних JavaScript-фреймворков, шрифтов и весов моделей. Названия и товарные знаки Groq, Gemini, ChatGPT, Microsoft и Kahoot используются описательно и не означают одобрения.

## Данные и учётные данные

Расширение Edge хранит учётные данные в локальном профиле Edge; в исходный архив они не входят. Отдельную зашифрованную копию пользователь может экспортировать сам; не помещайте её в репозиторий. Windows Desktop шифрует отдельные ключи через DPAPI CurrentUser в `%LOCALAPPDATA%\QuickAnswerDesktop\settings.json`; другие процессы того же пользователя всё равно могут получить к ним доступ. Приложение не защищает от скомпрометированной учётной записи Windows.

Текст и JPEG-снимки, отправляемые для ответа, передаются выбранному стороннему провайдеру. Проект не собирает статистику и по умолчанию не сохраняет снимки. Соблюдайте конфиденциальность данных и правила своего учебного заведения.
